# tth

A local small-model terminal agent. You describe what you want. tth inspects your real files in a read-only sandbox, tests a command, and puts it on your prompt. You decide whether to run it.

Early research preview, not ready for daily use. See the [project site](https://eeshwarantharan.github.io/tth/) and the [repository](https://github.com/eeshwarantharan/tth).
